# Horizon

A detective game using SFML GUI in C++. Uses Object Oriented Programming principles.

## How to Run

### Windows

- Run `setup.sh` if using `bash` or `setup.bat` on `windows`.
- Wait until execution is finished
- Run `run.sh` or `run.bat` depending on terminal

### Linux/macOS

- Make `setup.sh` executable if needed.
- Run `setup.sh`
- Wait until execution is finished
- Run `run.sh`

## Instructions For The Game

### How to play

On opening the game, you will be presented with a main menu. From there, you can start a new game or exit.
Choose from the following options to proceed with the game:

- Investigate Location: Explore different locations to find clues.
- Interrogate Suspect: Question suspects based on the clues you have gathered.
- View Evidence: Review the evidence you have collected.
- Make Accusation: Accuse a suspect you believe to be the murderer.
- Exit Game: Closes the application.

### Controls

- Click locations to enter.
- Click to search for clues
- Use the Accuse Button to accuse the murderer.

### Game Rules

- You must identify the murderer using logic and not by blind guesses.
- Clues are very important in finding the correct murderer; therefore, don't ignore them.
- Being nervous to answer the question does not mean that the suspect is a murderer. They could just be overwhelmed by the questions.
- Don't overquestion the suspects.
- Your final accusation is permanent and ends the game.
